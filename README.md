# FinTrack
A simple Next.js + React + TypeScript expense tracker.

## Run locally
Requires Node.js 20.9 or newer.
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Included
- Dashboard with balance, income and expense totals
- Add income and expense transactions
- Categories and dates
- Filter and delete transactions
- Spending breakdown by category
- Responsive layout
- Browser localStorage persistence

## Important limitations
This is a frontend project. Transaction data is stored locally in the browser and is not synced across devices.
